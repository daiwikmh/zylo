# Xaman (XRP Wallet) Integration Setup

This guide explains how to set up the Xaman wallet integration for FAsset minting with XRP payments.

## What is Xaman?

Xaman (formerly XUMM) is a non-custodial XRP Ledger wallet that allows users to sign transactions via QR code scanning or deep links.

## Setup Instructions

### 1. Get Your Xaman API Key

1. Go to [https://apps.xumm.dev/](https://apps.xumm.dev/)
2. Sign in or create an account
3. Create a new application
4. Copy your **API Key** (you only need the API key for browser-based apps, not the API Secret)

### 2. Configure Environment Variables

Create a `.env.local` file in the root directory (or copy from `.env.example`):

```bash
NEXT_PUBLIC_XUMM_API_KEY=your_xumm_api_key_here
```

**Important**: The API key must be prefixed with `NEXT_PUBLIC_` to be available in the browser.

### 3. How It Works

#### Step 1: Reserve Collateral
- User selects an agent and number of lots
- Smart Account pays the Collateral Reservation Fee (CRF)
- Transaction receipt contains:
  - XRP destination address (agent's XRP address)
  - Payment reference (hex memo)
  - Amount to send in XRP

#### Step 2: Send XRP Payment
- Xaman QR code is generated automatically
- User scans QR with Xaman wallet app
- Transaction includes:
  - **Destination**: Agent's XRP address
  - **Amount**: Calculated XRP (lots × 10 XRP + fees)
  - **Memo**: Payment reference (hex format)

#### Step 3: Confirm Minting
- Once XRP transaction confirms on XRP Ledger
- FAssets are minted to user's smart account
- User receives testFXRP tokens

## Testing

### Using Testnet (Recommended)

1. Install Xaman wallet app on your phone
2. Switch to **Testnet** mode in Xaman settings
3. Get testnet XRP from faucet: [https://xrpl.org/xrp-testnet-faucet.html](https://xrpl.org/xrp-testnet-faucet.html)
4. Scan the QR code generated by the app
5. Sign the transaction in Xaman

### Manual Payment (Without QR)

If the QR code fails to generate or you prefer manual payment:

1. Open your XRP wallet
2. Send to: `[Agent XRP Address]` (displayed in UI)
3. Amount: `[Exact XRP amount]` (e.g., 10.04 XRP)
4. Memo Type: **Hex**
5. Memo Data: `[Payment Reference]` (copy from UI, without 0x prefix)

## Troubleshooting

### QR Code Not Displaying

**Cause**: Xaman API key not configured or invalid

**Solution**:
- Verify `NEXT_PUBLIC_XUMM_API_KEY` is set in `.env.local`
- Restart Next.js dev server (`npm run dev`)
- Check browser console for errors

### Transaction Not Confirming

**Cause**: Memo might be incorrect or missing

**Solution**:
- Ensure you copied the **full payment reference** hex
- Use Memo Type: **Hex** (not Text or other types)
- Do not modify the amount or destination address

### API Rate Limits

Xaman API has rate limits. For production:
- Implement caching of payload UUIDs
- Consider using webhooks for transaction monitoring
- See: [https://xumm.readme.io/reference/rate-limits](https://xumm.readme.io/reference/rate-limits)

### Generate Payment Payload

```typescript

const result = await generateXamanPayload({
  agentUnderlyingAddress: 'rFBPRfA...', // XRP address
  totalAmountXRP: 10.04,                 // Amount in XRP
  paymentReference: '0x227234754b4a52...' // Payment reference hex
});

// Returns:
// {
//   qrUrl: 'https://xumm.app/sign/xxx/qr.png',
//   deepLink: 'https://xumm.app/sign/xxx',
//   uuid: 'xxx',
//   payload: { ... }
// }
```
